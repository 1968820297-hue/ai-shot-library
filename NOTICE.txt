Modifications in this edition: dark/blue editorial page layout and favicon,
Chinese default, custom theme, selected-shots view, recipe and video dialogs,
local download links, optional WebMCP filtering, and removal of social/contact
widgets. Modified website files include index.html, design.css, app.js,
translations.js, and build/server scripts.

The visual refactor adds consistent design tokens, image-led catalog rows,
a four-column desktop grid, a global motion-preview pause control, and 214 JPEG
posters extracted from the original local MP4s. No preview visuals were
generated or substituted. Reduced-motion preferences disable autoplay.

Git-tracked source ZIP without Git repository metadata. It is separate from
this derivative website's source package. The 214 preview MP4s were downloaded
separately into this website's media directory and are available through each
preview dialog.
